# Tic Tac Toe - fatalistic protection vs fatalistic death Edition ♟️

A beautiful console-based Tic Tac Toe game made in C++ with special runic symbols.

- **White (ᛉ)** goes first  
- **Black (𒉭)** goes second  

Just like in chess!

## Features

- Clean menu system
- 2D Array for board state
- Nested loops for board display and win checking
- Special Unicode symbols (ᛉ and 𒉭)
- Proper input validation
- Works perfectly on Dev-C++ 5.11

## How to Run

1. Copy the code into `main.cpp`
2. Compile and run using Dev-C++ or any C++ compiler
3. Enjoy the game!
